# Contract templates

Reusable client-contract templates for the digital-services business (websites, admin platforms, backends, automations — Margel360-style projects).

## Files

| File | Purpose |
|---|---|
| `digital-services-agreement-BG-EN.md` | Canonical bilingual (BG/EN) contract text — edit this first, then regenerate the others. |
| `digital-services-agreement-BG-EN.html` | Print-ready version (A4, two-column BG\|EN). Open in a browser → **Print → Save as PDF** to produce the copy you send. |
| `digital-services-agreement-BG-EN.docx` | Editable Word version (generated from the Markdown with pandoc), if present. |

## How to use per client

1. Open the HTML in a browser (or the .docx in Word) and fill in:
   - Contract **number and date**, city.
   - **Party details** for both sides: name, ЕИК/UIC, VAT no., address, representative, email.
   - **Bank details** in Art. 2(3) (IBAN, BIC, bank).
   - Client **contact person** in Art. 4(4).
   - **Annex A** — describe the services, deliverables, technologies, what's out of scope, and what materials/access the client owes you.
   - **Annex B** — total price, the 30% / 70% amounts, stages and deadlines.
2. Print to PDF (or export from Word) and send for signature. Sign **two counterparts** — one per party.
3. On delivery of each stage, use **Annex C** (handover-acceptance protocol) or an email confirmation — acceptance starts the 30-day warranty and makes the 70% balance due.

## Key terms built in (both-sides protections)

- **30% advance** on signing — work (and deadlines) start on receipt; 70% due on acceptance.
- **Deemed acceptance** after 5 business days of client silence, but the client gets a real review right + 2 revision rounds per stage.
- Deadlines auto-extend day-for-day when the client is late with materials/access/payments.
- **IP transfers on full payment** (exclusive, unlimited use rights under ЗАПСП); provider keeps pre-existing tools (perpetual license to the client) and a portfolio right.
- **Mutual liability cap** at the contract price; no indirect damages; statutory carve-outs preserved.
- Termination: 14-day cure period for breach; client may exit for convenience paying only for work done (advance set off, excess refunded); provider fault → refund of uncovered amounts.
- Bulgarian law, Sofia courts; **Bulgarian text prevails**; mutual confidentiality (3 years) and GDPR clause.
